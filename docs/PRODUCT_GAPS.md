# 产品改进与验收清单

目标：在一个 Windows 应用里完成已有实例开机、新建、克隆、任务管理与消息处理。功能存在、界面可达、实际可用分别验收，不以继承上游测试替代本应用实测。

参考本地已下载的 CrazyAutoDL engine/api/models 与 Stop-Manually-Refreshing-AutoDL-GPU 7f5bee9 源码。CrazyAutoDL 无明确许可证，未复制其源码；第二个项目保留 MIT 许可。

## 后续顺序

1. 共享登录已实现；继续实测平台会话刷新、退出、切换账号和重启行为。当前按凭据指纹保守绑定任务，尚未使用稳定账号 ID。
2. 统一任务中心：开机、新建、克隆共用任务状态、错误解释、暂停/恢复与历史入口；保留各自提交对账机制。
3. 账户页已加入余额、账单和低余额阈值，显示查询时间与失败原因，待用户实测。
4. 条件模板、筛选预览、失败恢复和导出脱敏诊断，减少重复配置。
5. 用户逐项实测：登录/退出/过期、库存匹配、一次开机、一次新建、一次克隆、断网及重启恢复。只有用户确认后才发布。

本轮已合并网页登录会话，尚未验证真实计费操作，不能宣称已全面超越两个参考项目。

## 胡闹 AutoDL 对照（0.4.0-test.1）

库存与槽位数量、自动开机、手动开关机、资源余量、释放时间、余额与低余额提醒、账单、托盘快捷操作、通知测试、离线演示均已在本地实现。SSH 与 Jupyter 入口也已加入。登录采用本应用统一专用浏览器，而非再开独立账号会话。

仍未照搬的部分：macOS 原生版及其字号设置（当前目标 Windows）；完整自动下载安装更新（本地测试阶段只检查版本与打开发布页）。资源余量用文字和数值展示，未复刻参考项目的圆形仪表装饰。账单图悬停显示日期和净额，逐笔记录在下方表格。
