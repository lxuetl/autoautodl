# AutoDL Companion 0.6.5-test.1

此版本为 Windows 预发布测试版，包含自 0.2.2 以来的本地迭代。

- 监控台统一仅开机、仅克隆、开机或克隆三种候补，只获取一台；提交意图持久化，结果不明时自动核实。
- 共用 AutoDL 登录和余额缓存；切换新建页面不再自动同步型号或重复网页核验。
- 克隆默认继承源实例配置；GPU 与磁盘按官方报价执行，提交前核对费用与余额。
- 动态 GPU 哨兵、多色资源仪表、深色卡片；修正报价、预算、消息详情和实例按钮的浅色背景。
- 消息中心支持搜索、事件/状态筛选、单条已读、复制和渠道发送详情；通知设置增加配置引导。
- 已有实例确认开机成功后接入微信/Webhook 队列，支持去重和失败重试。
- 修复便携版重复启动共用临时目录导致 Playwright 文件丢失；每次启动独立解压。

## 使用

下载 Windows.exe，彻底退出旧版（包括托盘）后运行。账号配置保留；无需删除用户数据。SHA256SUMS.txt 用于校验下载文件。

## 验证与限制

422 项自动化测试通过；本地打包界面、深色背景和 Playwright/Edge 启动检查通过。未使用真实账号进行付费租用或实际微信投递验证。AutoDL 页面或接口变更仍可能影响执行。程序未签名，任务持续运行需保持应用和专用浏览器开启。
