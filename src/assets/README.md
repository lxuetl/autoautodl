# autoautodl identity

Generated using the built-in imagegen tool; PNG is the master asset.
Design prompt: midnight navy rounded-square desktop icon, a bold geometric A formed from two looping arrow ribbons, turquoise/cyan and blue/violet gradients, readable silhouette, transparent outer corners, no wordmark.

`autoautodl.ico` packages 16, 24, 32, 48, 64, 128 and 256 pixel PNG frames converted from the master. The same master is used by the sidebar, Electron window, notifications and tray. Windows executable resource editing must remain enabled (`signExecutable: false` disables signing alone).

The visible product is autoautodl. The internal npm name and application ID remain unchanged for compatibility. User data stays at the existing `autodl-companion` directory.
